# Digital-Forensic-Project.
Digital forensics examination project for case AIT-DF-2026-009. Documents acquisition and Autopsy analysis of a replacement segmented disk image, including deleted-file findings, hash comparisons, screenshots, and investigation limitations. Evidence image files are excluded.
This repository contains the report and supporting records for a digital forensics examination conducted for case AIT-DF-2026-009. The analysis uses the replacement segmented image set Omonoa Rerun.001–.004 and the available Autopsy case exports. The report records acquisition details, deleted-file findings, cross-checks, and limitations. A separate Evidence.E01 appears in some earlier records; its relationship to the replacement image set has not been established. The forensic image files are not included in this repository.
